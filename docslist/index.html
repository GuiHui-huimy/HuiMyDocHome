    Tools¶

    This page lists all documentation sites and tools available in the HUI-MY ecosystem.

    Computational Biology Tools¶

    • GeneAnalyzer
      ---
      Gene expression analysis and variant calling pipeline.
      Documentation
      GitHub

    • :material-protein: ProteinFold
      ---
      Protein structure prediction using deep learning.
      Documentation
      GitHub

    • FlexTrimmer
      ---
      Machine learning-based protein flexibility analysis and trimming.
      Documentation
      GitHub

    High-Performance Computing¶

    • BioCUDA
      ---
      GPU-accelerated library for computational biology.
      Documentation
      GitHub

    • Vina-CUDA
      ---
      CUDA-accelerated molecular docking based on AutoDock Vina.
      Documentation
      GitHub

    • Protein Phaser
      ---
      High-performance C++ framework for PDB/mmCIF parsing.
      Documentation
      GitHub

    Molecular Simulation & Docking¶

    • Vina Virtual Screening
      ---
      High-throughput virtual screening workflow using AutoDock Vina.
      Documentation
      GitHub

    • GROMACS Simulation Suite
      ---
      Automated multi-system molecular dynamics simulation framework.
      Documentation
      GitHub

    • MD Analysis Toolkit
      ---
      RMSD, RMSF, Rg, and MM-PBSA analysis pipelines.
      Documentation
      GitHub

    Computational Chemistry & ML¶

    • RESP Charge Workflow
      ---
      Batch RESP charge calculation using ORCA and MultiWFN.
      Documentation
      GitHub

    • ResNet Predictor
      ---
      Deep learning model for molecular property prediction (planned).
      Documentation
      GitHub
