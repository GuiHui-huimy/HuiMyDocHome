# About HUI-MY Docs Hub

**HUI-MY Docs Hub** is the central documentation portal for the HUI-MY ecosystem.  
It gathers links, guides, and references for all HUI-MY projects — from computational biology tools to high‑performance computing libraries — into one organized place.

Whether you are looking for installation instructions, API references, or step‑by‑step tutorials, this portal helps you find the right documentation quickly.

---

## What is HUI-MY?

HUI-MY is a personal‑driven computational biology laboratory focusing on:

- **Enzyme engineering** and rational protein design  
- **Molecular simulation** and virtual screening  
- **High‑performance computing** with C++/CUDA  
- **Computational chemistry** and machine learning integration  

We not only use existing software but also build reusable underlying infrastructure for computational biology.  
Our goal is to lower the barrier to entry by openly sharing knowledge, code, and tools.

---

## What You’ll Find Here

The portal organizes documentation into several categories:

### Tools Documentation
Detailed guides for self‑developed tools and frameworks, including installation, usage, and examples.  
Examples: *Protein Phaser*, *BioCUDA*, *Vina‑CUDA*, *FlexTrimmer*, and more.

### Tutorials & Guides
Step‑by‑step tutorials covering common workflows, from getting started to advanced analysis pipelines.  
Examples: *Getting Started with HUI‑MY Tools*, *Workflow Examples*, *Molecular Dynamics Theory*.

### API References
Programmatic access documentation for REST APIs and Python SDKs where available.

### Community & Support
Links to forums, blogs, and main site for discussions, updates, and further help.
