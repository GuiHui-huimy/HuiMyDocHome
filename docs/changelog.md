## [1.0.0] - 2026-09-08

### Added

- Initial release of the HUI-MY Docs Hub documentation portal.
- Centralized documentation portal for HUI-MY ecosystem projects and tools.
- Categorized documentation sections:
  - Tools Documentation
  - Tutorials & Guides
  - API References
- Responsive home page with hero section, documentation cards, and community links.
- Integration with HUI-MY community sites (Lab, Forum, Blog, Main Site).
- Custom domain support (`docs.huimy.top`) with HTTPS enforced.
- Basic navigation structure: Home, About, Changelog.
- About page describing the portal and its purpose.
- Changelog page (this file) to track future updates.
